# 🤖 AutoCompany (AI 가상 회사 시스템)

사용자가 대표(CEO) 또는 고객의 입장이 되어 AI 직원들(기획자, 개발자, 디자이너, PM, 문서화 엔지니어 등)을 채용하고,  
격리된 도커(Docker) 환경에서 개발을 진행하며, 직원들 간의 토론, 피드백, 평가를 통해 직급이 매겨지고 성장하는 24시간 자율 AI 회사 시스템입니다.

---

## 📑 상세 시스템 설계서

프로젝트의 전체 객체 모델, 데이터베이스 스키마, REST API, 도커 격리 방식, 평가/승진 시스템, 바텀업 개발 로드맵은 아래 문서에 상세히 명시되어 있습니다.

👉 **[docs/DESIGN.md](docs/DESIGN.md)**

---

## 🚀 바텀-업 (Bottom-Up) 시작하기

서버 전체를 만들기 전, 로컬에서 단일/다중 AI 직원을 생성하고 도커 격리 환경에서 실행해 보는 로컬 에이전트 엔진부터 단계별로 구축합니다.
